MCP Transparency Log

An independent, continuously-operated record of what public MCP servers actually served.

Every night a crawler visits every server in the official MCP registry that declares a network endpoint, and records the exact tool surface it served. Observations go into an append-only Merkle log with a signed tree head published daily, so these figures can be recomputed rather than taken on trust.

This page is a derived view. The record is the log — verify it yourself:

go install github.com/yassinht/mcp-transparency-log/cmd/mcpobs@latest
mcpobs verify
